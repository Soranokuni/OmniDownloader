Recipes

A recipe is a short list of steps that finds the video on a page. The program ships a few; the model writes others, and you can import more. A recipe suspended on a site is not tried there until two canary checks in a row pass; a retired one never comes back. An imported recipe is a candidate: the videos it finds still wait for MCR's approval.

Test URL

Paste an article address to see what the program would do with it, without downloading, queuing or delivering anything: first what yt-dlp and the page sniffer say, and when both fail, what the repair ladder would try, with every candidate and its checks. It takes up to three minutes, and one test runs at a time.

Cookies

Some sites (X, Facebook, Instagram) show a video only to a logged-in account. Export the station account's cookies as a Netscape cookies.txt from a browser that is logged in, and upload them here, one file per site. They are encrypted on this machine and are never shown again. Only the lines of that site are kept. Use «Test» with a public link of the site to check that they still log in; it is repeated every night, and the Cookies health line turns amber when they are about to expire or stop working.

Benchmarks

Runs the stored 65-link corpus through the same tools as a job and reports how many links work, how long each step takes and how that differs from the last run of the same kind. «Extraction only» looks for the video and downloads nothing. «Full» also downloads, transcodes, rewraps and runs the compliance check, in a scratch folder: no job is queued, nothing is delivered to the watchfolder or archived. A run is refused while a job is running unless you tick the box, and only one run goes at a time.

LLM assist

The parser decides every job. The model is asked only where the parser is unsure (a journalist, a keyword, a group), and what it answers is checked before use. Any OpenAI-compatible server works, on this machine or online.

Online provider: each assist call sends the subject, part of the mail body, the roster surnames and the group names to this company. Email addresses and phone numbers are replaced with placeholders first, and the sender's address is never sent.

Newsroom taxonomy

Groups are the news desk, each show and each desk. A mail's group is decided from its subject, from "για …" in the body, or from the journalist's first group; the LLM chooses from this list only when none of those decide. The group is a label on the job: it never changes the file name or where the file is delivered.
